# Languages

English is the source and the default. If a translation key is missing, the UI shows the English string.

Coverage against English, from `frontend/`:

```bash
pnpm run locales
pnpm run locales -- --compact
```

Agents adding or editing a language follow [`.agents/skills/work-with-locale/SKILL.md`](../.agents/skills/work-with-locale/SKILL.md).
